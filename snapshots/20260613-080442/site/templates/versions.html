Major changes (new exit system, entry logic, timeframe, sizing, universe, risk regime) create a new version; logging, dashboard, and behavior-neutral fixes do not.

Environment Versions

A strategy version changes the organism; an environment version changes the measurement conditions (exchange, stake currency, universe construction, pairlist source). Each trade carries both, so we can separate "the strategy changed" from "the universe changed."
